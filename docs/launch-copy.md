# 发布介绍文案

## GitHub About

Evidence-based second reviews for completed projects in Codex: independent subagents, mandatory Astra xhigh adjudication, scoped repairs, and independent verification.

## 中文分享文案

给已完成的项目，一次有证据的独立复审。

Deep Project Review「项目深度复审」是一个 Codex Skill：多个真实子智能体独立检查，Astra · 极高核对证据、处理冲突与误报，再由主会话按难度安排授权内修复和独立验收。

支持代码、文档、表格、设计和演示材料。用户明确启动，默认最多两轮修复—复验，保留未提交改动，明确区分通过、失败、未运行和无法验证。

已完成 30 个行为决策案例，以及一个冲突夹具的 12 项实际断言。完整工作流尚未端到端验证，验证范围随项目公开。

## English share copy

Give finished work an independent review backed by evidence.

Deep Project Review is a Codex skill that combines focused independent subagent reviews, mandatory Astra xhigh adjudication, authorized repairs, and independent acceptance checks.

Explicit invocation. Scoped changes. Two repair–verification rounds by default. Clear reporting of what passed, failed, or could not be verified.

Authoring validation covers 30 decision cases and 12 executed assertions for a conflict fixture. The complete workflow has not yet been tested end to end; validation scope is documented openly.
